# Suggested Commands
- `pnpm dev` -> local dev server.
- `pnpm build` -> production build.
- `pnpm lint` -> ESLint.
- `pnpm test` -> Vitest run.
- `pnpm generate-types` -> regenerate `types/strapi.d.ts` from Strapi OpenAPI spec.
- On macOS terminal, prefer quoted paths for paths with spaces.
- For repo checks in this environment, use `rtk`-prefixed commands when running shell tools.
